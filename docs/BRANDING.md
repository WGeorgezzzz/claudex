# GACI brand

- Product name: **GACI** (always uppercase).
- Expansion: General Agent Cloud Integration.
- Tagline: Your agents, one workspace.
- Canonical mark: `public/gaci-mark.svg`; geometric G, ink `#132B2B`, soft white `#E8F5EF`, mint `#88E6BE`.
- Regenerate SVG/PNG/ICO/ICNS assets with `node scripts/release/generate-brand-icons.mjs`. `GACI_SHARP_MODULE` can point to an isolated Sharp installation.
- The WorkBuddy icon is the original SVG from the [WorkBuddy website](https://www.workbuddy.cn/), retrieved on 2026-10-24 from `https://assets.workbuddy.cn/web/workbuddy/a5b2fb510f0e7b156f19d072fae0cd12ae1f2f19/assets/logo.svg`. It remains WorkBuddy's provider mark.

Display names, installer filenames, browser/PWA icons, and the desktop launcher use GACI. Existing package/repository URLs, app IDs, protocols, storage folders, auth headers, and environment-variable names remain compatible. `gaci` is an additional CLI alias; existing aliases continue to work. The old `/claudex-mark.svg` asset URL serves the new mark for cached clients.

A display-name update does not publish a new installer or rename the GitHub repository. Preserve upstream licensing and notices.
